# One Tool One Sound

All these sounds have been created using only one tool. A max msp patch, a virtual instrument, a module, a prop I found on the street, a supercollider script, whatever it makes interesting sounds. It's an ongoing archive without any purpose if not gathering bits in one place. You can download the sounds directly from soundcloud, in case you use them it would be nice if you could credit me.
